## Description courte

Post-it Design permet d’ajouter, modifier, déplacer et organiser des post-it directement dans les Designs Jeedom.

## Description longue

Post-it Design ajoute une gestion visuelle de notes directement dans les Designs Jeedom.

Le plugin permet de créer des post-it, de les placer dans un Design, de modifier leur titre et leur contenu, de choisir leur couleur, leur style visuel et leur priorité, puis de les masquer ou les réafficher selon le besoin.

Une commande `+ Post-it` peut être installée dans un Design pour créer rapidement une nouvelle note sans quitter l’interface visuelle.

## Fonctions mises en avant

- Post-it affichables dans les Designs Jeedom.
- Création rapide depuis une commande `+ Post-it`.
- Modification du titre et du contenu depuis le Design.
- Couleurs rapides.
- Styles visuels `Classic`, `Paper`, `Tape`.
- Priorités `Normal`, `Important`, `Urgent`.
- Rotation et déplacement visuel.
- Masquage et réaffichage des post-it.
- Interface adaptée aux usages tactiles.
- Pas de démon.
- Pas de dépendances système.
